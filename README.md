 # FreshCatch – Fresh Fish & Seafood Marketplace

FreshCatch is a frontend e-commerce web application built using React and Vite. It allows users to browse fish and seafood products through a simple and user-friendly interface.

## Features

* Browse fish and seafood products
* Search and filter products
* View product details
* Add products to cart
* Manage wishlist
* Customer sign up and sign in
* Checkout and order confirmation
* View order history
* User profile management
* Admin dashboard
* Admin product, customer, and order management

## Technologies Used

* React.js
* Vite
* JavaScript
* HTML and CSS
* React Router
* Context API
* LocalStorage

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## Project Scope

This is a frontend-only project. It uses static product data and browser LocalStorage for data persistence. Backend integration and real payment processing are not included in the current version.
